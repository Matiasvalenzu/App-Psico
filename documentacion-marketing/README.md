# Documentacion para marketing y landing

Fecha de preparacion: 2026-06-29

Estos documentos resumen la aplicacion construida para que un experto en marketing, UX o una IA externa pueda entender el producto y trabajar la pagina web sin revisar el codigo fuente.

## Orden recomendado de lectura

1. `01-briefing-ejecutivo.md`: vision general, usuario objetivo, propuesta de valor y estado real del producto.
2. `02-funcionalidades-y-flujos.md`: detalle funcional por modulo y recorrido del psicologo.
3. `03-arquitectura-tecnica.md`: como esta construida la aplicacion, tecnologias, servicios y modelo de datos.
4. `04-ia-datos-privacidad-y-limites.md`: uso de IA, datos sensibles, privacidad, limites clinicos y claims que no se deben afirmar sin validar.
5. `05-material-para-landing-y-ventas.md`: mensajes comerciales, secciones sugeridas, angulos de venta, copy base y objeciones.
6. `06-prompts-para-otra-ia.md`: prompts listos para pegar en otra IA junto con estos documentos.
7. `07-roadmap-y-brechas.md`: funciones futuras, brechas comerciales y diferencias entre producto actual y producto ideal.

## Nota importante de marca

En el repositorio aparecen dos nombres historicos:

- `DatnexiA`: aparece en algunos assets anteriores y en la extension Chrome.
- `Psiconex`: aparece en la landing actual, login, layout reciente y textos nuevos.

Para marketing conviene unificar el relato en torno a `Psiconex`, salvo que se decida mantener `DatnexiA` como marca madre o empresa desarrolladora.

## Regla de uso para marketing

No presentar como implementadas las funciones marcadas como `roadmap`, `pendiente` o `dependiente de infraestructura`. En especial, evitar afirmaciones regulatorias o de seguridad que no esten implementadas y auditadas.
