# Prompts para usar en otra IA

Estos prompts estan pensados para que el experto en marketing pueda cargar esta carpeta como contexto en otra IA y pedir trabajo especifico.

## Prompt maestro

```text
Actua como estratega de marketing B2B SaaS especializado en healthtech y psicologia clinica. Voy a entregarte documentacion de Psiconex, una aplicacion web para psicologos clinicos.

Tu tarea es proponer una landing page que venda sin exagerar, respetando limites eticos: la IA no diagnostica, no reemplaza al psicologo y todo debe quedar bajo criterio profesional.

Lee la documentacion y entrega:

1. Propuesta de posicionamiento.
2. Hero con headline, subheadline y CTAs.
3. Estructura completa de landing.
4. Copy por seccion.
5. Objeciones y FAQ.
6. Claims que conviene evitar.
7. Recomendaciones de pruebas A/B.

Tono: profesional, empatico, concreto, sin hype de IA.
Publico: psicologos clinicos independientes y consultas pequenas en Chile/LATAM.
```

## Prompt para hero

```text
Usando la documentacion de Psiconex, genera 10 opciones de hero para landing.

Cada opcion debe incluir:

- Headline de maximo 9 palabras.
- Subheadline de maximo 28 palabras.
- CTA principal de 2 a 4 palabras.
- CTA secundario de 2 a 5 palabras.
- Nota del angulo persuasivo usado.

Restricciones:

- No prometer diagnostico automatico.
- No decir que la IA reemplaza al psicologo.
- No afirmar certificaciones legales no validadas.
- Evitar lenguaje exagerado como revolucionar, transformar, magico o next-gen.
```

## Prompt para estructura de landing

```text
Disena la estructura completa de una landing para Psiconex.

El producto ayuda a psicologos clinicos a registrar sesiones, transcribir audio, separar hablantes, ordenar fichas, aplicar tests, consultar el historial con IA, generar informes editables y gestionar agenda.

Entrega:

1. Orden de secciones.
2. Objetivo de cada seccion.
3. Copy sugerido para cada seccion.
4. Elementos visuales sugeridos.
5. CTA de cada seccion.
6. Riesgos o claims que deberian evitarse.

Hazlo para un publico de psicologos clinicos independientes en Chile. Tono sobrio, confiable y orientado a tiempo recuperado.
```

## Prompt para pagina de funcionalidad

```text
Genera una pagina o seccion especifica para la funcionalidad: [NOMBRE_FUNCIONALIDAD].

Contexto de Psiconex:

- Es una app para psicologos clinicos.
- Centraliza ficha, sesiones, transcripciones, documentos, tests, agenda, chat IA e informes.
- La IA apoya el registro y la preparacion, no diagnostica ni reemplaza criterio clinico.

Para la funcionalidad seleccionada entrega:

1. Headline.
2. Subheadline.
3. Problema que resuelve.
4. Como funciona en 3 pasos.
5. Beneficios concretos.
6. Microcopy de interfaz.
7. FAQ especifica.
8. Claims seguros y claims a evitar.

No inventes funciones no implementadas. Si no estas seguro, marcala como roadmap.
```

## Prompt para FAQ

```text
Genera una FAQ comercial para Psiconex con 15 preguntas frecuentes.

Debe cubrir:

- IA y limites clinicos.
- Consentimiento.
- Privacidad.
- Transcripcion.
- Sesiones online.
- Tests.
- Informes.
- Agenda.
- Exportacion de datos.
- Implementacion para consultas pequenas.

Cada respuesta debe tener maximo 55 palabras, tono claro y prudente. No afirmar cumplimiento legal, certificaciones ni seguridad no auditada.
```

## Prompt para objeciones de venta

```text
Actua como closer consultivo para vender Psiconex a psicologos clinicos.

Genera una matriz de objeciones con:

- Objecion del psicologo.
- Miedo subyacente.
- Respuesta recomendada.
- Prueba o demo que conviene mostrar.
- Claim que se debe evitar.

Incluye objeciones sobre IA, privacidad, consentimiento, precision de transcripcion, costo, tiempo de configuracion, sesgo clinico, tests y sesiones online.
```

## Prompt para copy de anuncios

```text
Genera 20 anuncios cortos para Psiconex orientados a psicologos clinicos.

Formatos:

- 5 para LinkedIn.
- 5 para Instagram.
- 5 para Google Ads busqueda.
- 5 para email subject lines.

Foco: tiempo recuperado, mejor registro, informes editables, historial consultable y control profesional.

Evita promesas exageradas, diagnostico automatico o claims legales no validados.
```

## Prompt para revisar landing existente

```text
Revisa la landing actual de Psiconex desde una perspectiva de conversion y cumplimiento de claims.

Evalua:

1. Claridad del hero.
2. Intensidad del dolor.
3. Credibilidad de claims tecnicos.
4. Coherencia con producto implementado.
5. Objeciones no respondidas.
6. Riesgo legal o reputacional.
7. Mejoras priorizadas.

Marca cualquier afirmacion que parezca no soportada por el producto actual, especialmente seguridad, cumplimiento legal, residencia de datos, tests disponibles y funcionamiento de sesiones Meet/Zoom.
```

## Prompt para una IA que generara el sitio completo

```text
Construye una landing page completa para Psiconex usando la documentacion adjunta.

Requisitos:

- Publico: psicologos clinicos independientes y consultas pequenas.
- Tono: profesional, empatico, directo, sin hype.
- Objetivo: generar solicitudes de demo o prueba.
- Debe explicar que la IA no diagnostica ni reemplaza al psicologo.
- Debe destacar: transcripcion, ficha clinica, voz, documentos, tests, agenda, chat IA e informes.
- Debe distinguir funciones implementadas de roadmap.
- Debe evitar claims no validados de cumplimiento legal o cifrado.

Entrega:

1. Wireframe textual.
2. Copy completo por seccion.
3. Componentes visuales sugeridos.
4. CTA principal y secundario.
5. FAQ.
6. Lista de claims prohibidos.
7. Recomendaciones para mejorar conversion.
```

## Prompt para estrategia de pricing

```text
Propone una estrategia de pricing para Psiconex considerando que es una herramienta SaaS para psicologos clinicos en Chile/LATAM.

Contexto:

- Funciones implementadas: pacientes, sesiones, transcripcion, voz, documentos, tests Ellis, chat IA, informes, agenda y Google Calendar.
- Costos variables posibles: DeepSeek, PyannoteAI, almacenamiento de audio, procesamiento CPU/GPU, soporte.
- Publico sensible al precio, pero con alto dolor por tiempo administrativo.

Entrega:

1. 3 modelos de pricing posibles.
2. Planes sugeridos.
3. Que limitar por plan.
4. Riesgos de cada modelo.
5. Recomendacion final para primera version comercial.
```

## Prompt para storytelling

```text
Escribe una narrativa de venta para Psiconex basada en un dia tipico de una psicologa clinica.

Debe mostrar:

- Agenda llena.
- Sesiones presenciales y online.
- Notas atrasadas.
- Necesidad de recordar detalles de un paciente.
- Envio de test.
- Generacion de informe.
- Como Psiconex reduce carga administrativa sin reemplazar su criterio.

Tono humano, sobrio y realista. Evita exageraciones.
```

## Prompt para convertir esto en brief de diseno

```text
Convierte la documentacion de Psiconex en un brief para disenador UI/UX.

Incluye:

- Personalidad de marca.
- Principios visuales.
- Jerarquia de secciones.
- Componentes clave.
- Estados de confianza y seguridad.
- Visuales de producto que conviene mostrar.
- Screenshots o mockups recomendados.
- Errores visuales a evitar.

Recuerda que el publico son psicologos clinicos: confianza, calma, claridad y sobriedad son mas importantes que espectacularidad tecnologica.
```
